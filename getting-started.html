Quickstart Guide

Getting Started with Taos Game Maker

Get your first tactical RPG project running in less than five minutes. Taos Game Maker comes pre-configured with a complete Godot 4 project and an instant local web studio.

System Requirements

Component Requirement Notes
Godot Engine Version 4.3 or newer Standard official build (No .NET/C# build required; 100% pure GDScript & Compatibility/Forward+ renderer).
Python Version 3.8+ Used strictly by the local web studio server (`editor/serve.py`). Uses only built-in standard libraries (zero pip dependencies).
Web Browser Any modern browser Chrome, Firefox, Safari, Edge, or Brave for accessing the local visual editing suite at `localhost:8000`.
Operating System Windows, Linux, or macOS Fully cross-platform development environment and export capabilities.
💡
Zero Configuration Hassle: You do NOT need to install node.js, npm, docker, or external databases. The entire editing suite runs locally out of the box with standard Python and Godot.

The 3-Step Setup Workflow

Once you acquire Taos Game Maker from Gumroad or itch.io, setting up the project takes three straightforward actions:

1

Extract the Package

Download `Taos_Game_Maker_vX.X.zip` and extract the contents to your preferred game development folder on disk.

2

Open in Godot 4

Launch Godot 4.3+, click Import, browse to the extracted directory, select project.godot, and open the project.

3

Launch Web Studio

Double-click start_editor.bat (Windows) or execute ./start_editor.sh (Linux/Mac) to launch the visual suite.

Launching the No-Code Web Studio

The visual suite runs a lightweight local server that hosts the 45+ visual editing tools in your web browser.

Terminal Command (Linux / macOS / Windows) CLI 
# On Windows: Double-click start_editor.bat
# Or run from terminal:
python editor/serve.py

# Output:
# [Taos Game Maker] Server started at http://localhost:8000/
# Press Ctrl+C to stop.

Your default web browser will automatically open to http://localhost:8000, presenting the complete Taos Game Maker design workspace.

First Steps in the Studio

The studio workspace is categorized into intuitive design suites:

  • Overworld Map Designer: Place terrain tiles, interactive POIs, monsters, dynamic weather triggers, and chest locations visually.
  • 3D Dungeon Architect: Assemble grid dungeon floors, place doors, torch fixtures, traps, and boss arenas in a 2D/3D hybrid viewport.
  • Tactical Combat Sandbox: Test enemy encounters, test turn order math, and balance skill synergies without launching Godot.
  • Visual Novel & NPC Graph: Connect dialogue branches with node graphs, configure facial portraits, and trigger quest conditions.
  • Database Managers: Dedicated visual managers for items, abilities, professions, achievements, world transforms, and music tracks.

Testing Your Game in Godot

To test changes in real time, simply click the «Test in Godot» button in the Web Studio toolbar, or press F5 inside the Godot editor.

ℹ️
Instant Synchronization: Whenever you save changes in the web editor, the modified JSON databases are updated on disk. Godot's autoload data managers load these definitions directly upon startup.
