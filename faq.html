FAQ & Commercial Licensing

Everything you need to know about licensing, platform capabilities, and using Taos Game Maker for your own commercial or indie projects.

No programming is required for core game creation. You can design complete world maps, assemble 3D dungeons, write branching dialogue trees, configure monster stats, build questlines, and balance items entirely through the 45+ visual tools in the included No-Code Web Studio Suite.

If you are a programmer, the entire Godot 4 project is provided in clean, modular GDScript with zero hidden binary blobs, giving you complete freedom to extend, customize formulas, or write custom shaders.
Yes, 100% royalty-free. When you purchase Taos Game Maker on Gumroad or itch.io, you receive a lifetime commercial license. You can sell your compiled games on Steam, itch.io, Google Play, Epic Games Store, or consoles, and you keep 100% of your revenue. You never owe royalties or licensing fees.
The package includes:
  • Complete Godot 4.3+ Project Template: Ready to open, customize, and export.
  • Local Web Studio Suite: Over 45 visual tools (Map Editor, 3D Dungeon Piece Architect, Dialogue Node Graph, Combat Sandbox, Item & Quest Wizards, Media Library, and QA Validator).
  • Full Core Subsystems: 3D Overworld, 1st-Person Grid Dungeon Crawler, Turn-Based Tactical Combat, Visual Novel Dialogue System, and City Crafting/Gathering.
  • Multiplatform Export Presets: Pre-tuned configurations for Windows, Linux, macOS, Android (APK/AAB), and Web (HTML5).
  • Starter Assets: Base models, textures, interface graphics, sound effects, and music tracks.
Taos Game Maker includes tested and pre-configured export presets for:
  • Windows Desktop: 64-bit standalone executable (`.exe`).
  • Linux / X11: Native 64-bit binary (`.x86_64`), compatible with desktop Linux and Steam Deck (SteamOS).
  • macOS: Universal binary supporting both Intel and Apple Silicon (M1/M2/M3/M4).
  • Android: Standard APK and Google Play Store App Bundle (`.aab`).
  • Web (HTML5): Playable directly in browser via WebAssembly/WebGL.
Zero DRM, zero telemetry, zero subscriptions. Taos Game Maker is a one-time purchase. The local web studio and Godot engine run completely offline on your computer. You own the files forever.
Echoes of Truth (Ecos de la Verdad) is our full-length tactical RPG built 100% on top of Taos Game Maker. It serves as both a complete standalone game and a living, playable demonstration of the engine's capabilities. You can play it for free on itch.io or download it from Gumroad.
The only restriction is that you cannot re-sell, redistribute, or open-source the raw Taos Game Maker engine source code, project template, or studio suite as an engine or asset product. You can distribute and sell any compiled game you build with it without restrictions.
