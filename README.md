## 🚀 What is Taos Game Maker?

Taos Game Maker is a complete, production-tested JRPG framework for **Godot 4.3+**, paired with a **local web studio of 45+ visual tools** that lets you design entire games without writing a single line of code. Every game system — combat, quests, dialogues, items, skills, dungeons, shops, cutscenes — is driven by **plain JSON files**, so if you can edit a text file, you can build a full JRPG. The included studio runs entirely on your machine (local Python server + your browser, no accounts, no subscriptions, no cloud), and everything it produces is 100% yours.

This is not a theory or a toy: **Echoes of Truth**, a complete tactical JRPG with ATB combat, first-person dungeons and a branching story in 7 languages, was built entirely with this framework — and it ships **free** as living proof and as a giant, fully moddable reference project.

**Four game genres, one framework:**

| Genre | What you get |
|---|---|
| 🗺️ 3D Overworld | Grid-based world exploration, towns, NPCs, events |
| 🕯️ First-Person Dungeon Crawler | Atmospheric 1st-person grid dungeons |
| ⚔️ Tactical Combat | Turn-based tactical battles with ATB timing, buffs & party management |
| 💬 Visual Novel | Branching narratives, dialogue trees & cutscenes |

## 🛠️ Three levels of control

1. **No-code** — design everything through the visual web studio (45+ tools, runs at `localhost:8000`).
2. **Low-code** — open any JSON file and tune values, stats, dialogues, loot tables…
3. **Full control** — the complete Godot project is included: extend or rewrite any system in GDScript.

You are never locked in. Start visual, go as deep as you want.
